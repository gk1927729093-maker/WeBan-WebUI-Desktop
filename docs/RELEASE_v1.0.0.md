# WeBan WebUI Desktop 1.0.0

基于 [wu-xiao-ya/WeBan-webui](https://github.com/wu-xiao-ya/WeBan-webui) 修改，底层运行程序来自 [hangone/WeBan](https://github.com/hangone/WeBan)。保留上游 GPL v3 许可证，项目来源和修改对照详见仓库首页与 `UPSTREAM.md`。

## Windows 安装包

下载 `WeBan-WebUI-1.0.0-x64.msi`，适用于 Windows 10/11 64 位，约 52 MiB，内置 Python 3.12 及依赖。电脑仍需已有 Edge 或 Chrome，并能连接课程平台。

附带 SHA256 校验文件、安装说明和本机验证摘要。安装包未进行代码签名，Windows 可能显示发布者未知。

## 主要修改

- 批量导入账号，运行中可继续追加，不重启其他账号。
- 持续队列、并发排队，默认跳过已完成账号。
- 按账号分类的实时和历史日志，最终考试成绩展示。
- 每账号实时章节进度，并按“运行中 / 未运行”分组。
- 完成超过 24 小时的进度自动单独归档，最近完成的暂留控制台。
- 完成状态基于最终进度与及格结果核验，避免将恢复后的错误误判为未完成。
- AI 请求与学习会话隔离，模型、鉴权和额度错误分类处理。
- 标准 MSI 安装与卸载，支持自定义目录；卸载停止后台并保留用户数据。

## 数据与验证

发布内容不含维护者的账号、密码、Token、API Key、运行日志或历史完成记录。安装版数据位于 `%LOCALAPPDATA%\WeBanWebUI\Data`，与程序安装目录分开。

首个 MSI 已在本机完成安装、启动、重复启动、停止、自定义路径卸载与数据保留验证，包内 1914 个文件核对一致。当前并发上限为 50，更大规模并发和其他电脑环境没有完成实际验证。
